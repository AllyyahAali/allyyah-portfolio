# Allyyah Aali — portfolio

A static, responsive portfolio for GitHub Pages. Open `index.html` locally to preview it.

## Publish on GitHub Pages

1. Create a new public repository, for example `allyyah-portfolio`.
2. Upload `index.html`, `style.css`, and the `assets` folder to the root of the repository.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The project site will appear at `https://AllyyahAali.github.io/allyyah-portfolio/` once GitHub finishes publishing.

The site uses relative asset paths, so it works at a GitHub Pages project URL. It needs no build step. The reference images supplied for design inspiration are not republished; the project images and portrait come from Allyyah's own work files. The 1985 Society and Equity in Action images are identified as concepts or planning work.

Before sharing widely, review the project descriptions, figures, and how your contribution is described. The GitHub profile is currently the contact link; add a preferred email or LinkedIn URL if desired.
